Write a plan for the work the request asks for, from the request, the app's rules and what reading the repository found, never from what you remember of similar code elsewhere. Nothing is changed yet. The tasks change code: a document or a run alone is not that work. Each task finds its own code when it runs. Plan only what the request asks, the simplest way that does it, with what the language, its standard library and the repository already provide: no task for work the request did not ask for. Every task is proved afterwards by its walks: steps done in the running app by someone who never sees the code.
