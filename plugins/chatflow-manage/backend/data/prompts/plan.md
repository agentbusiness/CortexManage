Write a plan for the work the request asks for. Nothing is changed yet.

1. Plan from the request, the app's rules and what reading the repository found, never from what you remember of similar code elsewhere.
2. Plan only what the request asks, the simplest way that does it, with what the language, its standard library and the repository already provide.
3. Every task changes code: a document or a run alone is not a task. Each task finds its own code when it runs.
4. Every task is proved afterwards by its walks: steps done in the running app by someone who never sees the code.
