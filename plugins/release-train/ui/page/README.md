# @cortex-ui/release-train-page

The Releases view of a repository: tonight's train (parts, now → next, what each carries), the
detents **Release now** and **Skip tonight**, what soaks in your apps, and the released list with
**Take back** on each package. The repository comes from the shared selection (`manage.selection`).

- **Plugin id:** `release-train.page`
- **Slot:** `page.releases@1`
- **Build:** `npm run build` → `dist/` (`index.js`, `style.css`, `manifest.json`)

React, ReactDOM and `@cortex/sdk` are peer dependencies the workbench provides.
